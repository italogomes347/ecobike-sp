
# 🚲 EcoBike SP

**Mobilidade sustentável, prática e acessível para São Paulo!**

O EcoBike SP é um projeto de site desenvolvido para apresentar um serviço fictício de aluguel de bicicletas por hora. A plataforma permite conhecer os modelos disponíveis, calcular valores de aluguel e cadastrar pré-reservas diretamente no navegador.

## 🌱 Sobre o projeto

O objetivo do EcoBike SP é incentivar a mobilidade urbana sustentável por meio de uma experiência digital simples, moderna e responsiva.

O site foi desenvolvido como projeto acadêmico, utilizando HTML, CSS e JavaScript.

## 🚴 Modelos de bicicletas

| Modelo | Valor por hora |
|---|---:|
| Urbana | R$ 12,00 |
| Elétrica | R$ 20,00 |
| Cargo | R$ 25,00 |

### 💰 Simulador de aluguel

O usuário pode selecionar o modelo de bicicleta e a quantidade de horas desejada para visualizar o valor do aluguel.

- Cálculo automático do preço.
- Desconto de 10% para aluguéis acima de 5 horas.
- Validação dos valores informados.
- Exibição detalhada do cálculo.

## ✨ Funcionalidades

- Página inicial com apresentação da marca.
- Catálogo de bicicletas disponíveis.
- Filtros para facilitar a busca por modelos.
- Simulador de valores de aluguel.
- Sistema de pré-reservas com inclusão e remoção de nomes.
- Armazenamento das pré-reservas utilizando LocalStorage.
- Alternância entre modo claro e escuro.
- Layout responsivo para computadores, tablets e celulares.
- Navegação entre páginas independentes.

## 🛠️ Tecnologias utilizadas

- **HTML:** estruturação e organização do conteúdo.
- **CSS:** estilização, responsividade, animações e layouts.
- **JavaScript:** funcionalidades, cálculos, validações e interações.
- **LocalStorage:** armazenamento local das preferências e pré-reservas.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Navegue pelas páginas e utilize as funcionalidades disponíveis.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para executar o projeto durante o desenvolvimento.

## 🌐 Publicação

O projeto pode ser publicado gratuitamente utilizando o **GitHub Pages**.

Após habilitar o GitHub Pages nas configurações do repositório, o site ficará disponível por meio de um endereço público.

## 📌 Observação

O sistema de pré-reservas é demonstrativo e utiliza o armazenamento local do navegador. Portanto, os dados ficam salvos apenas no dispositivo e navegador utilizados, não representando uma reserva real.

## 🎓 Finalidade acadêmica

Projeto desenvolvido com finalidade educacional, aplicando conceitos de desenvolvimento web, HTML semântico, CSS responsivo e programação JavaScript.
